# What a helper can do

Everything on this page happens at
[careers.globalfurry.tv/account/translations](https://careers.globalfurry.tv/account/translations),
under **Translating**.

## Edit your language freely

You can write and rewrite your language across the whole site. There is no
approval step in front of saving, and nothing waits on anybody.

If you help with more than one language, each is a tab at the top.

## See what is left

The list shows everything in your language that is:

- **Not started**, with no translation at all.
- **Drafted**, started and not yet finished.
- **Finished**, waiting for an admin to mark it ready.

Filter it by what kind of thing it is, and by which of those three states it is
in.

## Find something that is already done

A finished translation is not on that list, so there is a search box above it.
Search by the English name.

That is how you go back and improve a translation nobody has complained about.

## Writing a posting

The editor puts your language beside the original, field by field. Fill in what
you can and save. You can come back as often as you like.

A few things it tells you as you go:

- **The original leaves this empty**, when there is nothing to translate in a
  field.
- **This translation is not live yet.** Save as often as you like. An admin
  marks it ready once it is finished.
- **This translation is live.** What you save changes what readers see now, so
  it cannot be left without a title, a summary and a description.

A posting may carry up to twenty extra sections in a translation.

## A translation may be a different shape

Your language does not have to have the same number of sections as the
original. Some things need two paragraphs in English and one in 华文, and
sometimes the reverse.

What a live translation cannot do is drop the title, the summary or the
description. A translated heading above an untranslated body is worse than
plainly untranslated.

## Teams and tags go live at once

A posting has a draft state. A team name or a tag name does not.

> This one has no draft state. A team or tag name appears wherever it is used
> as soon as you save it.

Take a little more care with those. There is no reviewer between you and the
filter labels.

## What you cannot edit here

**Interface wording.** The labels, buttons and messages are in the code and not
in the database. Changing one is a change a developer makes and a deploy
carries.

You can still say what is wrong with one. Suggest it in place and it goes into
the same queue as everything else. See [Suggesting a correction in
place](/translations/suggesting-in-place).

## Leaving without saving

If you navigate away with unsaved words in the editor, the site asks first:

> What you have typed here has not been saved, and leaving will lose it.
