# 指令参考

一共九个指令，而且没有 `/help`。`/start` 的讯息里就有那些内容，
所以您发出的第一个指令，也是解释其余指令的那一个。

输入其他任何内容，都会得到一行字，指回 `/start`。

## 指令

| 指令 | 返回什么 |
|---|---|
| `/start` | 机器人的用途、指令列表，以及通往入队平台的按钮。 |
| `/link` | 绑定按钮在哪里，给先找到机器人的人看。 |
| `/unlink` | 解除绑定，需要先确认。 |
| `/code` | 为已绑定的账户发一个新的登录验证码，附复制按钮。 |
| `/invites` | 您还没处理的邀请，每一个都附一个通往该职位的按钮。 |
| `/tasks` | 有多少事情在等您，以及一条通往它们的链接。 |
| `/applications` | 您的申请，以及每一个目前的状态。 |
| `/jobs` | 最新的空缺，每一则都附一个通往该职位的按钮。 |
| `/notify` | 选择哪些通知会送到聊天里。 |

## 每个指令会返回什么

### /start

国际兽视入队平台是什么，以及完整的指令列表。列表分成两部分：
现在就能用的指令，以及尚未做好或目前被关掉的指令。
下方是通往入队平台和支持国际兽视的按钮。

同一则讯息也处理账户设置里的那条绑定链接。点那条链接会送出一个带码的 `/start`，
机器人会回答绑定的结果，而不是介绍。

### /link

给先找到机器人才找到网站的人。它会说明按钮在哪里，并给您一个按钮打开账户设置。
请看[绑定您的账户](/bot/linking)。

如果这个 Telegram 账户已经绑定，它会改为说明这一点。

### /unlink

会请您确认，附上 **是的，解除绑定** 和 **保持绑定**。
在您按下其中一个之前什么都不会发生。请看[解除绑定](/bot/unlinking)。

讯息可以被转发，所以按钮会检查按下的人是谁。别人按下会被拒绝。

### /code

发送一个新的六位数字登录验证码，附一个可以复制它的按钮。
验证码只能用一次，有效期五分钟。

有两件事必须先成立：这个 Telegram 账户必须已绑定，
而且您的账户必须设定为登录时索取验证码。
少了第二项，验证码就没有地方可以输入，所以机器人会告诉您开关在哪里，而不是发码给您。

您每小时可以索取十二个验证码。超过之后它会请您等大约半小时，
并说明在这段时间里可以用双重验证备用码。

### /invites

您还没处理的邀请，最多五个，每一个都附一个打开该职位的按钮。
下方有一个通往您待办事项页面的按钮，并提醒您每一份邀请那里也有，
连同发出邀请的人所写的内容。

您已经回应过的邀请，或团队已撤回的邀请，都不会列出。
请看[职位邀请](/bot/invitations)。

### /tasks

一个数字和一个按钮，绝不是一份列表。
一件待办事项可能带有一组必须准确回答的问题。
让聊天窗口去转述它，会是两边都最糟的做法。

那个数字算的是您[待办事项](/portal/outstanding-tasks)页面上的项目，
包括任何关于您是否申请了某个职位、尚未回答的问题。

### /applications

您最多五个申请，每一个都附上入队平台使用的状态词，以及一个通往完整列表的按钮。
已关闭和已归档职位的申请也会列出，因为您随时都可以重读自己申请过的内容。

九个状态在[我的申请](/portal/your-applications)上有说明。

### /jobs

最新的五个空缺，每一则都附一个通往该职位的按钮，另有一个按钮通往整个职位板。
结尾是每一份列表都有的那一句：除非职位另有说明，
否则国际兽视的职位都是义务性质、没有报酬的。

**这一个不需要账户，也不需要绑定。** 职位板是公开的，
所以先找到机器人的人也可以问问有什么职位。

它读的是网站用来建立职位板的同一个公开数据源。
聊天和职位板不可能对现在有什么职位说法不一。

### /notify

三个开关，每一类通知一个，各自显示目前的状态。请看[通知](/bot/notifications)。

## 当某个指令不作答时

两句不同的话，意思也不同。

**将于第 5 阶段推出。** 那个指令还没有做好。
国际兽视入队平台是公开地分阶段发布的，
讯息里提到的阶段是从[开发进度页面](https://careers.globalfurry.tv/status)读来的，
不是写死在讯息里的。

**我们正在修理，暂时无法使用。** 那个指令是好的，只是管理员暂时把这个功能关掉了。
有时会附上一段说明。它会回来。

这两者绝不会混淆。如果有人被告知上周还在用的东西要等未来的阶段，
那会让一次真实的故障看起来像一个还没做的功能。

## 按钮会一直有效

机器人画出的每一个按钮，在重启之后、在一个月之后，都仍然保持原本的意思。
按钮里带的只是一个不透明的编号，此外什么都没有。
转发讯息里的按钮无法被变成对您账户的操作。

一个比它背后记录更旧的按钮会这样说：

> 这个按钮太旧了，无法执行。请重新发送该指令。
