# 绑定您的账户

绑定一律从入队平台开始，在[账户设置](/portal/account-settings)的 **Telegram** 底下。
按 **绑定 Telegram**，面板会给您一个二维码和一条链接。

**它必须从那里开始，不能从聊天开始。** 那一页已经知道是哪个账户登录着，聊天窗口不知道。
一个接受用户名的机器人，可能被诱导把您的账户绑到别人的 Telegram 上。

## 从电脑

1. 打开[账户设置](https://careers.globalfurry.tv/account/settings)，
   找到 **Telegram** 面板。
2. 按 **绑定 Telegram**。
3. 用装有 Telegram 的手机扫描二维码。
4. Telegram 会打开机器人。按 **开始**，机器人会确认。

面板会告诉您这个码还剩多少时间。它只能用一次，有效期十分钟。

## 从装有 Telegram 的那台手机

同一个面板，只是没有东西要扫。按 **打开 Telegram**，链接会在那台设备上打开应用。
**复制链接** 是给您贴到其他任何地方用的。

## 成功时机器人会说什么

> 完成。这个 Telegram 账户现在已绑定到 Sam。

它用的名字是您入队平台账户上的显示名称，如果您没有设，就用您的用户名。
如果它写出一个您不认识的名字，请看[疑难排解](/bot/troubleshooting)。

## 如果这个码不管用

机器人会用一句话作答，不给细节：

> 这个码不管用。请在入队平台上打开账户设置，取得一个新的，马上就能使用。

这一句同时涵盖三种情况：这个码已经用过、已经过期，或者根本不是我们发的。
**这三者是刻意无法分辨的。** 告诉某人是哪一种，
等于告诉任何拿到转发链接的人这个链接值不值得再试一次。

请在面板里按 **显示新的码**。索取新码没有次数限制。

## 双方都只能绑一个

一个 Telegram 账户绑定一个入队平台账户，一个入队平台账户绑定一个 Telegram 账户。
想绑第二次会得到这个：

> 这个 Telegram 账户已经绑定。如果您想绑到另一个入队平台账户，请先发送 /unlink。

在这么做之前请先看[解除绑定](/bot/unlinking)，因为它会改变您登录的方式。

## 从机器人这边开始

如果您先找到机器人才找到网站，向它发送 `/link`。
它会回答该怎么做，并附上一个按钮帮您打开账户设置。
它无法自行完成绑定，理由在本页开头。

## 绑定之后可以开启什么

链接一存在，Telegram 面板就会多出三样东西。

- **发送测试消息。** 应该会在半分钟内送达，这是证明整条路径都通的最快方法。
- **登录时向 Telegram 索取验证码。** 这就是第二步验证。
  请看[用 Telegram 登录](/bot/signing-in)。
- **解除 Telegram 绑定**，和在聊天里发送 `/unlink` 是同一件事。

> [!WARNING]
> 在让您开启第二步验证之前，网站会请您先生成 **双重验证备用码**。
> 万一您失去 Telegram，它们就是回去的路。
> 没有备用码就开启它，是账户永久丢失的原因。

## 没有东西只送到 Telegram

无论聊天里发生什么，每一份邀请、团队的每一个请求、每一次申请的进度更新，
都会在您的账户页面上。绑定只是多一条更早知道的途径，它绝不会变成唯一的途径。
