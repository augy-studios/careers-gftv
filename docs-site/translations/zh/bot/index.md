# 使用 Telegram 机器人

国际兽视入队平台有一个 Telegram 机器人：
[@careersgftv_bot](https://t.me/careersgftv_bot)。
把它绑定到您的账户，它会在有事情发生时告诉您，也让您更快登录。

它是选用的。它送给您的一切在入队平台上也都有，
所以一个没有绑定 Telegram 的账户什么都不会错过。

## 它能做什么

- **让您登录。** 第二步验证的六位数字验证码，或者一条按一下就好的链接。
  请看[用 Telegram 登录](/bot/signing-in)。
- **在您受邀申请某个职位时告诉您**，附上一个按钮可以阅读职位，
  还有一个按钮可以婉拒。请看[职位邀请](/bot/invitations)。
- **在团队问您问题时告诉您**，以及您的某个申请有进展时。请看[通知](/bot/notifications)。
- **回答关于您账户的问题。** 您还没处理的邀请、有多少事情在等您，
  以及每一个申请目前的状态。
- **列出最新的空缺**，这不需要账户，也不需要绑定。

## 它不能做什么

- **替您申请职位。** 申请是一份 Google 表单，在浏览器里打开。
  机器人可以把职位的链接发给您，仅此而已。
- **给您看整则职位。** 它发的是标题和一个按钮。
  职位很长，聊天窗口不是合适的形状。
- **自行开始绑定。** 向它发送 `/link`，它会告诉您按钮在哪里。
  它没有办法知道哪个入队平台账户是您的。
  一个在这里接受用户名的机器人，可能被诱导去绑定别人的账户。
- **处理任何员工账户的事。** 招聘负责人和管理员在网站上登录。
  机器人只认识申请人账户。
- **停止发送登录验证码。** 有三类通知可以关掉，这一类不行。
  验证码只会在有人正在登录您的账户时才送出。

## 它绝不会向您索取任何机密

机器人绝不会向您索取密码、恢复码或备用码。
它发给您的任何东西，都不需要您把这些打回聊天里。

如果 Telegram 上有讯息向您索取其中任何一项，那不是我们。

## 两种语言

机器人以英文和华文作答。您的账户绑定之后，它会使用您账户上设定的语言，
也就是您在入队平台上选的那一个。

在绑定之前，它跟随您 Telegram 应用的语言设定。
