# 索取更多资料

**待办事项** 是您向申请人索取东西的方式。
它会出现在他们的待办事项页面上，如果他们绑定了 Telegram，也会到那里。

请从追踪页面上、在相关的那份申请上提出。

## 两种类型

**请求** 是要对方给您东西。
它会一直开着，直到他们回复而您把它结案。

**通知** 是单向的。它说明某件事，对方标示为已读。
录取和婉拒会自动送出一则通知，所以那两种情况您不必自己提出。

## 讯息

一个主旨和一段正文，由您撰写。没有范本。

请说明您需要什么以及为什么。
「请给我们一条您做过的作品链接，让我们看看风格」
会得到比「请提供作品样本」更好的答案。

## 问题

选填，最多二十个。它们会把一件待办事项变成一份小表格。

四种类型：

| 类型 | 对方得到什么 |
|---|---|
| 简答 | 一行 |
| 详答 | 一个方框 |
| 单选 | 从您给的选项里选一个 |
| 多选 | 从您给的选项里选任意多个 |

每一个问题都可以标示为必答。

对于两种选择题，每一个选项都有一个 **值** 和一个 **标签**。
值是答案实际储存的内容，在每一种语言里都相同。标签是申请人读到的文字。

他们会在 **一次提交** 里回答完所有内容，下方还有一个自由填写的方框可以补充。
这是一个回合，不是一场对话。

> [!WARNING]
> 待办事项一经送出，它的问题就固定了。
> 事后再编辑会让答案对应到没有人问过的问题，所以这件事没有办法做。

送出前请先读一遍。那是唯一的机会。

## 用不只一种语言

请用您能写的语言写那个问题。
留空的语言会回退到有写的那一个。

那是问题旁边的一则说明，不是问题本身。
读华文的申请人会拿到英文的问题，那比完全没有问题好。

## 四种状态

| 状态 | 意思 |
|---|---|
| 开启中 | 已送出，对方还没有回复 |
| 已回复 | 他们回答了，接下来轮到您 |
| 已完成 | 由员工结案 |
| 已消除 | 一则通知，对方标示为已读 |

**已回复** 是要留意的那一个。
追踪页面会标记带有未结案待办事项的那一行，
所以除非没有人打开那一页，否则不会有东西被忽略。

## 读取回复并结案

他们的回复会出现在那份申请上，在待办事项下方。
对您那些问题的答案会照顺序，显示在各个问题旁边。

拿到您需要的东西之后，请按 **标示为已完成**。
一件一个月前就回答了却从未结案的待办事项，仍然会显示在对方自己的页面上。
它告诉对方有人在等他们，而那并不是真的。

## 申请人会看到的另一种待办事项

**您申请了这个职位吗？** 那一件是网站提出的，不是您，
在有人打开申请表单之后出现。他们的回答会把状态设为已申请。

您会在他们的记录上看到它。请不要去动它。
隔夜的排程过一阵子就会放弃它，而已确认提交会让它根本不必存在。

## 待办事项不能做什么

**它不能夹带文件。** 本站任何地方都不接受上传。请索取链接。

**它无法编辑，也无法收回。** 请另外提出一件说明情况，并把第一件结案。

**它不是电邮。** 除了一则指回本站的 Telegram 讯息之外，没有任何东西离开本站。
