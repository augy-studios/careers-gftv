# 链接预览那一行

把职位的链接贴到 Discord、Telegram 或其他地方，
会出现一张卡片，有标题和下面一行字。**链接预览那一行** 就是指那一行。

编辑器会在栏位下方显示卡片实际的样子。

## 留空它就会做对的事

留空时，预览会使用职位描述的第一句。
那通常是对的，编辑器也会这样说明。

当第一句单独拿出来当开头很不好看时，就自己写一句。
一段以「这是摄影棚团队三个职位之一」开头的描述，
作为别人唯一看到的那一行会很难读。

请保持在一句以内。预览卡片的空间非常小。

## 它一律以英文提供

> [!WARNING]
> 链接预览一律以英文提供，不论链接是用哪种语言分享的。
> 在翻译分页上写的华文，不会出现在 Discord 或 Telegram 里。

原因在于预览的运作方式。
展开链接的那个网站是一台在抓取页面的机器，它没有语言偏好可以提供。
我们这一边没有东西可以读取。

所以翻译分页上的这个栏位，诚实地说明它今天什么都不做。
您想写就写，只是目前没有东西会呈现它。

## 卡片上还有什么

职位的 **标题**，以及网站自己的图片。两者都不是按职位设定的。

卡片上没有摘要、标签、团队或截止日期。您能得到的就是一行字。

## 它不影响什么

**搜索。** 这一行不会改变一则职位在职位板上或在搜索引擎里被找到的方式。

**职位页面。** 这一行不会出现在页面本身的任何地方。

它就是一句话，被看一次，看的人正在决定要不要点进去。全部就是这样。
