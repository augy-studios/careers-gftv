# 您会看到哪些东西是灰掉的

国际兽视入队平台是公开地分阶段发布的。
您看得到的东西里，有一部分还没有做好，它会在控件上直接说明，而不是默默失败。

控件不照您预期运作有三种原因，而这三种是刻意做得互不相同的。

## 1. 还没有做好

> 将于第 5 阶段推出。造成不便，敬请见谅。

控件在那里，灰掉的，点它会打开一段说明，写明是哪个阶段，以及那个阶段涵盖什么。

**这是计划，不是故障。** 没有东西坏掉，也不需要通知任何人。
[开发进度页面](https://careers.globalfurry.tv/status)列出每一个阶段以及哪些已经上线。

阶段编号就是从同一个文件读来的，所以控件和进度页面不可能说法不一。

## 2. 目前被关掉

> 我们正在修理，暂时无法使用。

那个功能是好的，只是管理员把它关掉了，
通常是在故障期间，或在修理某样东西的时候。有时会附上一段说明。

每一个管理后台页面顶部都有一行字，说明有几项功能被关掉了。
等有人重新打开时它就会回来。没有东西会自己打开。

**分辨这两者很重要。**
如果有人被告知上周还在用的东西要等未来的阶段，
那会让一次真实的故障看起来像一个还没做的功能。

## 3. 不属于您

控件是 **不存在的**。没有灰色、没有说明，也没有东西可以点。

这是刻意的。灰掉已经代表「将于稍后的阶段推出」。
拿它来代表「您没有权限」，会让一项权限看起来像一个开发状态。

对招聘负责人来说，不存在的有：

- **员工权限** 和 **申请人账户**，侧边栏里没有。
- **设置** 和 **维护**，侧边栏里也没有。
- 职位上的 **删除**，以及追踪记录上的 **删除**。
- **未匹配提交**，在分析页面底部。

如果您需要其中某一项，请找管理员。
没有任何东西是基于对您的评价而对您隐藏的。

## 申请开关

有一个开关值得知道，虽然它不属于您。
管理员可以在整个职位板上关闭申请。

关闭期间，每一个职位上的申请控件都会停用，
申请人会被告知本站目前不接受申请。
职位仍然可以阅读，也没有东西被删除。

**那是一个政策上的选择，读起来也就是那样**，和某样东西坏掉不是同一回事。
如果您的职位突然不能申请了，请先问一声，不要直接当成故障。

一次更改大约要一分钟，才会传到一个已经打开着职位页面的人那里。

## 当某样东西真的坏了时

既不是前面那两句话，也没有缺少控件：就只是一个错误。

请说明您当时在做什么、在哪一则职位上，以及大概的时间。
网站保有稽核日志，其余的管理员找得到。
