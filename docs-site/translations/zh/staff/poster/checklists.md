# 两份检查清单

两份清单可以照着走。第一份是每则职位一次，第二份是每周一次。

## 发布新职位之前

**文字**

- 标题说的是职位，不是团队。
- 摘要单独读起来也通顺。那是别人在卡片上看到的东西。
- 关于这个职位、您会做什么、需要您具备什么，三项都填了。
- 报酬写对了。除非勾选框另有说明，否则就是无薪。
- 地点和投入程度都设了，或者是刻意留空的。

**设定**

- 至少一个标签，而且每一个都是别人会拿来筛选的标签。
- 有团队，或者刻意不放。
- 设了截止日期，或者 **招满为止** 正是您的本意。
- 名额就是您实际要找的人数。

**表单**

- 表单地址是长网址，不是短链接。
- 表单正在接受回复，而且会收集电邮地址。
- 您自己已经向它提交过一次测试回复。
- 回复表格已经填上了。
- 预填对照表填好了，或者是刻意跳过的。
- 已确认提交设置好了，或者是明知情况下跳过的。

**最后看一眼**

- 在新标签页预览，并以一个不在这里工作的人的角度读一遍。
- 每一个翻译分页要么是 **已完成**，要么是刻意留着的。
- 发布，然后打开上线中的那则职位，自己按一次申请。

最后这一项要花十五秒。
它能抓到本站代价最高的错误：一则已发布的职位，申请按钮通往任何地方。

## 每周检视

**概览**

- 每日维护显示上一次运行已完成。
- 没有职位被标记为表单不可用。
- Telegram 队列在移动。
- 草稿里没有搁着本来该发出去的东西。

**流程**

- 没有任何一份申请停在 **已申请** 一整周都没人碰。
- 每一件标示为 **已回复** 的待办事项都已经读过并结案。
- 停在 **已发出邀约** 的人都得到了答复，或者知道什么时候会有。
- 婉拒都送出去了。沉默是本站最糟的事。

**职位板**

- 每一则已发布的职位都还需要找人。
- 过了截止日期的都已经关闭，而且是刻意关闭的。
- 没有截止日期的职位现在看来仍然合理。

**数字**

- 没有职位带着 **检查表单** 的标记。
- 两周前发布的职位没有几乎无人浏览的情况。那是标签和标题的问题。
- 全部都是自行申报的「是」。那份表单值得好好设置一次。

## 每个月值得做一次的事

打开 **标签**，筛出没有职位使用的标签，把它们清掉。
然后把整份列表看一遍，找出两个意思相同的标签，把它们合并。

十分钟。
这就是一个别人筛选得动的职位板和一串词之间的差别。
