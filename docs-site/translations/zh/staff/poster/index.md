# 使用管理后台

这是国际兽视入队平台员工管理后台的指南。
它写给拿到账户、而且从来没见过管理界面的义工看。
这里没有任何地方假设您知道什么是短代号或 webhook。

管理后台在
[careers.globalfurry.tv/admin](https://careers.globalfurry.tv/admin)。
职位在那里撰写、发布和下架，申请也在那里处理。

## 两种角色，您是其中一种

能打开管理后台的人，不是 **招聘负责人** 就是 **管理员**。
侧边栏顶部的标签会说明您是哪一种。

招聘负责人撰写职位并处理申请。管理员同样会做这些，另外还负责营运整个网站。
如果您是管理员，本指南对您仍然完全适用，
[管理员指南](/staff/admin)是叠在它上面的那一部分。

**有四样东西属于管理员，它们根本不在您的侧边栏里：**

- **员工权限**，决定还有谁可以打开管理后台。
- **申请人账户**，也就是申请背后的那些人。
- **设置**，包括首页文案、精选职位、等待期，以及职位板是否接受申请。
- **维护**，也就是把已上线功能在全站关掉的那些开关。

另外还有四样比较小的东西属于管理员：

- 永久删除一则职位。
- 从追踪页面删除记录。
- 分析页面底部的未匹配提交列表。
- 授予某人翻译帮手的角色。

您能打开的页面上，其余的一切都是您的。

**翻译队列是您打得开、而本指南不涵盖的一项。**
回报和语言稽核在[管理员指南](/staff/admin)里，因为处理那个队列本身就是一份工作。
公开的[翻译指南](/translations)说明读者那一半。

您不被允许使用的控件是 **不存在的**，绝不是灰掉的。
在这里，灰掉代表另一回事。请看[您会看到哪些东西是灰掉的](/staff/poster/what-is-disabled)。

## 管理后台里没有什么

**别人在申请表单上写的答案。** 那些留在 Google 表单里。
本站记录的是谁被交给了哪一份表单，以及每个人进行到哪里。
每一行都会链到那则职位的回复表格，答案在那里。

**电邮。** 本站任何地方都没有电邮。您在这里做的任何事都不会寄电邮给任何人。
申请人被告知的一切都落在他们的待办事项页面上，如果他们绑定了 Telegram，也会到那里。
