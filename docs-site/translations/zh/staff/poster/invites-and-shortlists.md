# 邀请与候选名单

侧边栏的 **邀请**。每则职位有两份名单，两者的差别就是这一整页的重点。

![邀请与候选名单](pending:poster-invites-desktop-light "一则职位，候选名单在受邀名单上方。")

**候选名单是不公开的。** 它标记您正在考虑谁，而完全不告诉他们。

**邀请会送到本人手上。** 它连同您写的内容落在他们的待办事项里，
如果他们绑定了 Telegram，也会送到那里。

## 加人

选好职位，按 **加人**，然后用姓名或用户名搜索。
任何有申请人账户的人都找得到，不论他们有没有申请过什么。

您想选几个就选几个。撰写视图会在您送出之前说明这是给谁的。

**要说什么** 是一个栏位，它做两件不同的事：

- 在 **邀请** 上，它会原样显示给申请人看。
- 在 **候选名单** 上，它是一则不公开的备注，说明他们为什么在名单上。

然后按 **静静列入候选** 或 **邀请**。

## 邀请在他们那一边长什么样

他们待办事项页面上的一项：职位、您的讯息，以及一条通往那则职位的链接。
他们可以从那里打开职位，像其他人一样申请。

申请仍然是申请。邀请不是跳过表单、跳过问题，或跳过等待期的捷径。

## 受邀名单上的各个状态

| 状态 | 意思 |
|---|---|
| 未告知 | 已列入候选。什么都还没送出。 |
| 已邀请 | 已送出，但还没有打开。 |
| 已看到 | 他们打开了。 |
| 已申请 | 他们申请了那个职位。 |
| 已婉拒 | 他们婉拒了。 |
| 已撤回 | 您把邀请收回了。 |

## 撤回

**撤回** 会停止关于那份邀请的任何提醒。

它不会把已送出的讯息收回。
他们手上已有的讯息仍然留在那里，记录也仍然留在这一页上。
本站没有任何东西可以收回已送出的内容。

## 批量邀请

选了几个人，就会给他们每一个人送出同一则讯息。
确认画面会说明这会送达多少人。

> [!WARNING]
> 邀请无法收回。
> 在用一则讯息邀请二十个人之前，请再读一遍那则讯息。

请为这一群人写。
一则读起来像私人讯息、却送给二十个人的内容，比一份诚实的公开邀请更难看。

## 什么时候用哪一个

**候选名单** 用在您还在决定的时候。
它对申请人没有任何代价，也不告诉他们任何事，而它是您据以工作的那份名单。

**邀请** 用在您希望某人来申请、而且会很乐见他们申请的时候。

不要把申请过某个已关闭职位的人全部邀请一遍。
那些人在追踪页面上有记录，而他们在等的是一个决定。

## 这一页不是什么

**不是讯息通道。** 这里没有对话，也没有回复。
如果您需要对方给您什么东西，请提出一件待办事项。
请看[索取更多资料](/staff/poster/asking-for-more-information)。

**不是告诉某人他们没被选上的方式。**
那在追踪页面上，决定和讯息会一起被记录下来。
