# 待翻译稽核

**待翻译** 是翻译页面上的第二个分页。
它列出还没有人翻译的内容，不论有没有人抱怨过。

[队列](/staff/admin/translations-queue)是抱怨。这里是沉默。

![稽核](pending:admin-needs-translation-desktop-light "稽核列表，包含三种状态以及每一行缺了什么。")

## 三种状态

| 状态 | 意思 |
|---|---|
| 未开始 | 这个语言完全没有任何内容。 |
| 草稿中 | 有人写了一份，但没有标示为就绪。 |
| 部分缺失 | 它已经上线，而且比原文单薄。 |

**完成的翻译不在这份列表上。**
列表列的是还剩下什么，所以空的列表正是您想要的答案。

可以按语言和按状态筛选。每一则职位、团队和标签都在范围内。

## 怎么看待一份单薄的翻译

**部分缺失** 是最值得弄懂的状态，因为那些读者此刻正在被服务。

**缺了什么** 那一栏会列出翻译留空、而原文有填的那些栏位：
摘要、职位描述，或额外区块。

**已上线但单薄，和坏掉不是同一回事。**
一则职位没有标题、摘要和职位描述就无法标示为就绪，所以那必备的三样都在。
缺的是那三样以外的东西。

**额外区块通常就是答案。**
翻译可以带着和原文不同数量的区块，那是刻意的，而稽核仍然会把差距算进去。
请看[额外区块](/staff/poster/sections)。

> [!NOTE]
> 单薄是一个判断，不是一个缺陷。
> 一份省略了作者认为不必要的区块的翻译，是某个人做出的决定。

## 一行该怎么处理

**打开列表** 会带您到需要撰写的地方。

它有三种被写出来的方式：

- **您来写**，在职位编辑器的语言分页里。
- **帮手来写**，如果有人持有那个语言的角色。
  请看[翻译帮手](/staff/admin/translation-helpers)。
- **没有人写**，读者会看到原文。那是目前的行为，而且不是错误。

**把语言标示为就绪是员工的事。**
帮手可以起草一切，但不能让任何东西上线。
请看[翻译帮手](/staff/admin/translation-helpers)。

## 当分页说没有东西可以稽核时

**本站只有一种语言，所以没有东西可以稽核。**
那句话代表网站正以单一语言运行。
在 `gftvjobs_locales` 里加上第二种语言，这里就会有内容。
