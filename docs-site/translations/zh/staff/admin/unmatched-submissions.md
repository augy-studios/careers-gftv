# 未匹配提交

在 **分析** 页面的最下方，而且只有管理员看得到。
读同一页的招聘负责人完全看不到这个区块。

![未匹配列表](pending:admin-unmatched-desktop-light "没有对应账户的提交，每一笔都附一个对应控件。")

## 什么会落到这里

**表单是用一个没有任何账户在使用的电邮地址提交的。**

这只会发生在设置了已确认提交的地方。
表单告诉网站是谁提交的，网站去找那个电邮，结果找不到人。

**常见的原因很平淡。**
某人用了和注册时不同的地址申请：表单上填工作地址，账户用的却是私人地址。

**这不代表有什么不对。**
不论哪一种情况，申请本身都安然留在 Google 表单里。

## 对应一笔

**对应到某个账户** 会打开一个搜索。
用姓名、用户名或电邮地址找到那个人，然后对应过去。

对应会做什么：

- **把那份申请记录为已提交。**
  状态不再依赖申请人事后告诉我们。
- **从现在起算，启动再次申请的等待期。**
- **不动那个账户自己的电邮地址。** 它不会被改成表单上的那一个。

如果那个人自己已经回答过「是」，对应会取代那个回答。
**一笔被记录下来的提交胜过一个错过的提示**，所以已确认的那一个胜出。

> [!WARNING]
> 请对应到正确的人。
> 这一页上没有任何东西能证明表单上的那个地址属于您即将选中的那个账户。

如果不明显，请先和对方确认。
一个背上自己没做过的已确认提交的申请人，比一个还在等待对应的申请人更糟。

## 当这里空无一物时

**每一笔提交都已经对应到账户了。**
那是正常状态，而一份越来越长的列表值得当成一个信号来读。

同一则职位上出现好几笔未匹配，通常代表那份表单问电邮的方式让大家答得不一样。
在一笔一笔对应之前，先看看表单上那个问题本身。

## 这份列表不是什么

**它不是所有的申请。** 申请在追踪页面上。

**它不是别人正在处理的队列。**
这里没有东西会过期，也没有东西会催您。
一笔记录会一直待着，直到某位管理员把它对应掉。
