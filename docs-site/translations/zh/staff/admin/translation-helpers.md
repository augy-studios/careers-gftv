# 翻译帮手

**帮手** 是翻译页面上的第三个分页，招聘负责人没有这一个。
回报队列和稽核对任何员工账户都开放。
这个分页，以及上面的每一个操作，都会拒绝没有 `is_admin` 的人。

**帮手是一个普通的申请人账户**，被授予了编辑某一种语言翻译的权利。
不是员工账户。最有能力修好华文的人，没有理由必须是国际兽视的员工。

这件事公开的那一面是[翻译指南](/translations)，任何人都读得到。

## 这个角色能打开什么

**整个语言，在整个网站上。** 每一则职位、每一个团队、每一个标签。
没有办法只授予网站的一部分。

**他们可以自由起草，不需要审批，也不必等待。**
他们写的职位内容会一直是草稿，直到有人把那个语言标示为就绪。

> [!NOTE]
> 团队或标签的名称没有草稿状态。
> 帮手一保存，它就会在所有用到的地方改变。
> 只有职位前面才有一道闸。

**他们不能让职位上线。**
把语言标示为就绪是员工的事，
所以帮手在职位上写的任何内容，在有人读过之前都不会到达读者。
正是这一点，让这个角色可以在建立信任之前就授予。

**他们可以在页面上直接提出建议**，用他们持有的那种语言。
请看[在页面上提出的建议](/staff/admin/suggestions-in-place)。

## 授予它

**授予帮手角色。**
请先选语言，再用姓名、用户名或电邮地址找到那个账户。

对话框会在您同意之前说明您同意的是什么：
整个语言、不能发布，以及没有办法再缩小范围。

**原因是必填的。**
它会留在那一行上，一年后有人会从这份列表读它，
所以请说明他们是谁，以及是谁推荐的。

## 看懂这份列表

| 栏 | 内容 |
|---|---|
| 帮手 | 那个账户，以及他们持有的语言。 |
| 已起草 | 他们写了多少。 |
| 已回报 | 他们提出过的回报，以及还有几份没结案。 |
| 授予时间 | 什么时候，由谁授予。 |

**由一个已被移除的账户授予**，代表当初授予的那位管理员已经不在了。
授权仍然有效。

某一行上的 **无法登录**，代表那个账户已被暂停。
角色仍然持有着，在他们被挡在外面期间不起作用。

## 撤销它

**撤销** 会拿走那个语言，账户本身不受影响。

- **他们写过的一切都会留下**，不论有没有上线。
- **他们会失去那个语言的帮手区域。**
- **那一行会被删除。**
  您写的原因和稽核日志，是他们曾经持有过这个角色的唯一记录。

这里也必须填写原因，而且理由比平时更尖锐：
日后没有一行「已撤销」的记录可以让人从上面读到它。

## 大家会问的两件事

**管理员可以在页面上直接提出更正吗？**
只能用他们自己的申请人账户，而且那个账户要被授予帮手角色。
员工是读那一层的，不写入它，因为回报是记录在申请人账户上的。

**撤销会不会撤销他们的成果？** 不会。
帮手写过的任何内容都不会因为失去角色而被还原。
如果某个翻译是错的，就去修那个翻译。
