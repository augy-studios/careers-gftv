# 管理员指南

**这本指南是叠在[招聘负责人指南](/staff/poster)上面的那一部分。**
那本指南里的一切对您完全适用。
您撰写职位、处理申请，而且是在招聘负责人用的同一批页面上做这些事。

这里写的是其余的部分：招聘负责人打不开的那些管理后台，
以及营运这个网站而不只是使用它所带来的工作。

## 哪些是您的、别人没有的

**有四个区块在您的侧边栏里，不在招聘负责人的侧边栏里。**

| 区块 | 决定什么 |
|---|---|
| 员工权限 | 还有谁可以打开管理后台。 |
| 申请人账户 | 申请背后的那些人。 |
| 设置 | 首页文案、精选职位，以及职位板是否接受申请。 |
| 维护 | 把已上线功能在全站关掉的那些开关。 |

**另外还有四样比较小的东西也是您的**，在招聘负责人打得开的页面上：

- 永久删除一则职位。
- 从追踪页面删除记录。
- 分析页面底部的未匹配提交列表。
- 授予某人翻译帮手的角色。

**翻译队列是您和别人共享的一项。**
招聘负责人打得开它。处理它本身就是一份工作，所以写在这里，不写在他们的指南里。

## 哪些不是您的，而且从来都不是

**账户本身属于 gftv.asia。**
本站不建立员工账户、不设定员工密码，也不发放 admin 或 editor 角色。
它决定的是某个账户能不能从这道门进来。
请看[谁能进来](/staff/admin/access-and-roles)。

**本站任何地方都没有电邮。** 您做的任何事都不会寄电邮。
如果有事要告诉某人，那会落在他们的待办事项页面上，
如果他们绑定了 Telegram，也会到那里。

## 本指南的内容

1. [谁能进来](/staff/admin/access-and-roles)，以及那些标记和覆写如何组合。
2. [管理员工权限](/staff/admin/staff-access)：允许、拒绝，以及把决定交还回去。
3. [申请人账户](/staff/admin/applicant-accounts)，
   包括为被锁在外面的人提供的协助操作。
4. [翻译队列](/staff/admin/translations-queue)：从头到尾处理一份回报。
5. [待翻译稽核](/staff/admin/needs-translation)，也就是还没有人抱怨过的部分。
6. [翻译帮手](/staff/admin/translation-helpers)：授予角色，以及收回它。
7. [在页面上提出的建议](/staff/admin/suggestions-in-place)，
   更正抵达队列的另一条路。
8. [入队平台设置](/staff/admin/portal-settings)：首页、精选职位，以及申请开关。
9. [维护开关](/staff/admin/maintenance-switches)，在某样东西坏掉时使用。
10. [未匹配提交](/staff/admin/unmatched-submissions)，以及手动对应一笔。
11. [每日运行](/staff/admin/daily-run)，以及它汇报某件事时该怎么办。
12. 已发布职位上[坏掉的申请表单](/staff/admin/a-broken-form)。
13. [当有人无法登录时](/staff/admin/cannot-sign-in)，两个体系都涵盖。

开发说明文件是另外一个区块，您的账户打得开它。它是给处理代码的人看的。
