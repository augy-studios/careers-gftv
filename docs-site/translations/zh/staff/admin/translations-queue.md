# 翻译队列

侧边栏的 **翻译**。读者告诉我们哪里读起来不对，以及还没有人翻译的部分。

这一页有三个分页。这里说的是 **回报的问题**。
另外两个是[待翻译稽核](/staff/admin/needs-translation)
和[翻译帮手](/staff/admin/translation-helpers)。

![队列](pending:admin-translations-queue-desktop-light "回报列表，筛选到一种语言。")

**侧边栏上的数字是还没结案的数量。**
一份回报被接手时它就会减掉，不是等到处理完成。

## 一份回报从哪里来

两道门，一个队列。

- **职位底部的回报表单。** 任何人都能用，不需要角色。
- **在页面上直接选取**，来自一位把用词标示出来并提供替代写法的帮手。
  请看[在页面上提出的建议](/staff/admin/suggestions-in-place)。

可以按语言、按内容类别、按来源，以及按状态筛选。

## 四个状态

| 状态 | 意思 |
|---|---|
| 开启中 | 在等人处理。回报抵达时就是这个状态。 |
| 处理中 | 有人接手了。它仍然留在队列里。 |
| 已修正 | 用词改了。需要一段说明。 |
| 不是问题 | 现在的用词是对的。需要一段说明解释为什么。 |

## 处理其中一份

**打开** 会把回报和用词并排给您看。

**他们选取的那些字** 会以提出回报时的样子显示。
如果那些字已经不在文本里，回报会说明，并仍然显示那个建议。
用词很可能在那之后被改过了。

**他们建议的写法** 是他们的，而且绝不会自行套用。
编辑框里是什么，保存的就是什么。

**现在读起来是怎样** 显示的是那个语言目前的用词。
如果那个语言还没有这一项的翻译，读者看到的是原文，而保存就等于开始写一份翻译。

> [!NOTE]
> 您在这里开始的翻译，在有人于职位编辑器里把那个语言标示为就绪之前，都不会发布。
> 保存用词不等于让它上线。

**采用他们的写法** 会把那个建议复制到编辑框里。保存之前请先读一遍。

**保存用词** 只保存用词，别的都不做。它不会把回报结案。

## 结案

**答复这份回报** 是后半部分，而且是另外一次保存。

选好状态，然后写下发生了什么。
**提出回报的人会一字不差地读到您写的内容**，就在他们自己的账户页面上。

**标示为已修正或不是问题时，说明是必填的。**
包括他们弄错了的时候。他们毕竟费心告诉了我们。

## 有些您在这里修不了

**界面用词在代码里。**
导航、按钮和每一个标签都在 `assets/i18n` 里，正是那一点让网站可以离线使用。
关于那些的回报会显示它的键，而且这里刻意没有编辑器。

要修就得编辑那个文件并部署。请在说明里写清楚。

**有些回报没有指明是哪一部分。**
要么是读者没有说明哪些字读起来不对，
要么是那一部分必须连同周围的内容一起编辑。
**在编辑器中打开** 会带您到那则职位，并把他们的说明放在旁边。

## 这一页不是什么

它不是从零撰写翻译的地方。
那是职位的编辑器，以及持有角色的人所用的帮手区域。

它不是让翻译上线的地方。
把一个语言标示为就绪是在编辑器里、在那则职位上做的。
