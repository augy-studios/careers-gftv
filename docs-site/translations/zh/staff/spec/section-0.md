# 0. 写任何代码之前，先读这些

1. 读代码库根目录的 `gftv-theme.md`，并把那套主题套用到你做的每一个页面。不要自创新的颜色、字体或组件样式。
0. 先把这整份文件从头到尾读一遍，然后才做别的事。
2. 读根目录的 `index.html`，把它的 `<head>` 当作本代码库里其他所有 HTML 文件 `<head>` 的模板。meta 标签、字体链接、主题初始化脚本和 manifest 链接都要跟它一致。
3. 如果这两个文件缺了任何一个，先停下来告诉我，然后才继续。
