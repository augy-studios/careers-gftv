# 1. 我们在做什么

**国际兽视入队平台**是 Global Furry Television 的招募平台，网址是 `careers.globalfurry.tv`。它以 `jobs.careers.gov.sg` 为蓝本。那是一个干净的公开职位板，有搜索和筛选的列表、每个职位自己的详情页，还有需要登录的申请流程。后面另有一个私人的管理后台。

它是一个国际兽视 HelloApp，所以它遵循其他国际兽视 PWA 的同一套惯例。
