# 员工说明文件

这些是给营运国际兽视入队平台的人看的指南：招聘负责人指南、管理员指南，
以及开发说明文件。您在下面看到什么，取决于您的账户。

**这些指南有英文和华文两个版本**，本站的这一半也一样。
用页首的地球图标切换，还没有人翻译的页面会以英文显示，并附上说明。
招聘负责人属于员工，而招聘负责人指南是这里读者最广的一本。

- **[招聘负责人指南](/staff/poster)** 已经写好，涵盖整个管理后台：
  撰写和发布职位、连接申请表单，以及处理申请。
- **[管理员指南](/staff/admin)** 已经写好，建立在前者之上。
  员工权限、申请人账户、翻译队列、各项设置，以及维护开关。
- **[开发说明文件](/staff/developer)** 已经写好，给处理代码的人看。
  规格书、数据库、身份验证、Vercel、服务工作线程，以及那些值得不必重学的惯例。
