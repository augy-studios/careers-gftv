# 申请职位

申请分两部分：Google 那边的一份表单，加上我们这边的一个问题。
之所以有这个问题，是因为 Google 表单无法告诉我们您有没有按下提交。

## 按下申请后会发生什么

1. **网站记录您已开始申请。** 从这一刻起，这个职位会以 **已开始**
   出现在[我的申请](/portal/your-applications)上。
2. **申请表单在新标签页打开**，使用 Google 表单，并预先填入您已经给我们的资料。
   通常是您的姓名和电邮，如果表单需要，也包括电话号码。
3. **入队平台的标签页留在原处**，并显示一个小面板，请您做完之后回到这里。

请让入队平台的标签页开着。后半部分就在那里完成。

> [!NOTE]
> 如果您的浏览器挡住了新标签页，这不是出错。面板会说明，
> 并给您一个按钮，可以正常打开表单。

![按下申请后显示的面板，包含评分和「您申请了吗」这个问题。](pending:portal-apply-dialog-desktop-light "您回来时看到的面板。它的两个部分都是选填的。")

## 您回来时要回答的问题

回到入队平台的标签页时，它会问两件事。两件都不是必填的，直接关掉面板也没关系。

**为这则职位信息评分。** 选填，满分五分。它评的是这则信息写得好不好，
不是这个职位本身，也不是您的机会。有了它，团队才会在二十个人被劝退之前，
知道某则信息让人看不明白。

**您申请了这个职位吗？** 两个答案：

- **是的，我申请了。** 申请会记录为已提交，日期是今天。
  它会移到您申请页面上的 **已申请**，而再次申请同一职位前的三个月等待期从这里开始计算。
  请看[再次申请](/portal/applying-again)。
- **还没有。** 什么都不会锁上。这个职位对您仍然开放，下次会再问一次。

**关掉面板而不回答，视为还没有。** 这个问题不会消失。
它会在您的[待办事项](/portal/outstanding-tasks)页面上等着，作为关于那个职位的一个问题。
职位上的申请按钮会变成提示，请您回答它。
如果一直没有人回答，十四天后系统会自动放弃。

只要关于某个职位的问题还没有回答，您就无法对同一个职位开始第二次申请。
按钮上的提示就是这个意思。只有回答它才能继续。

## 我们保存什么，不保存什么

- **我们不保存您的答案。** 您在申请表单里填的一切都交给 Google，留在 Google 那边。
- **本站任何地方都不接受上传文件。** 如果某个职位需要看您的作品，它的表单会说明方式。
- **我们保存您申请过这件事，以及时间。** 那就是您申请页面上的那一行，也是团队据以处理的依据。

撤回申请或删除账户，都不会删除您透过 Google 表单送出的内容。
如果您需要移除那些资料，请联系团队。

## 当申请按钮写着别的内容

按钮会如实反映您所处的状态，一共有八种。

| 按钮上写着 | 意思 |
| --- | --- |
| 申请这个职位 | 一般情况。 |
| 您有一个关于这次申请的问题尚未回答 | 请先回答那个问题，按下会重新打开面板。 |
| 已于 3 月 4 日申请，6 月 4 日起可再次申请 | 您申请过了，三个月等待期正在计算。 |
| 您已获录取 | 您拿到这个职位了。这一项永远不会变成日期。 |
| 不再接受申请 | 职位已关闭或已过截止日期。 |
| 目前全站暂停接受申请 | 全站的一个开关被关掉了，这则职位本身没有问题。 |
| 这个职位还没有设置申请表单 | 这是我们要处理的，不是您的问题。如果一直如此，请告诉团队。 |
| 您的回答已保存，恢复网络后会送出 | 您在没有网络时回答了。请看下文。 |

## 离线申请

您无法离线申请。申请是一份 Google 表单，需要网络，
网站会照实说明，而不是默默失败。

离线时能用的是您回来看到的那个面板。在没有网络时给出的评分和「是」或「否」的回答，
会保存在您的设备上，等网络恢复后自行送出。

**排队中的回答是等待送出，不是已完成。** 在服务器确认之前，它不算一次申请，
也不会启动三个月的等待期。申请控件会说明它正在等待送出，那才是实情。
