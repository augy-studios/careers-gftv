# 使用入队平台

国际兽视入队平台是国际兽视 (Global Furry Television) 发布招募职位的地方，您也在这里提交申请。
网址是 [careers.globalfurry.tv](https://careers.globalfurry.tv)。
本指南涵盖平台的全部内容，从开设账户到忘记密码后重新登录。

## 目前列出的所有职位都没有报酬

这一点最重要，所以放在最前面。目前站上的每一则职位都是义务性质，没有报酬。
包括高级职位、员工职位，以及建造本站的人。今天国际兽视没有人拿薪水。

它叫入队平台，是因为这里是空缺所在，不是因为空缺附带薪水。
每则职位会标明需要投入多少时间，所以一个职位可以诚实地写着 **全职**，同时仍然是全职的义工职位。
如果将来出现有薪职位，那则职位会在自己身上写明。
这是记录在每则职位上的资料，不是靠人记得去更新的一句话。

## 阅读不需要账户，申请才需要

每则职位都完整公开：职位描述、您会做什么、需要您具备什么、投入程度、地点和截止日期。
整个职位板也一样，包括筛选功能。没有任何内容被模糊处理，也没有为会员保留的部分。

只有两件事需要账户：申请职位，以及收藏职位以后再看。

## 申请前需要准备什么

- **一个账户**，注册只需片刻。没有审核队列，也不必验证电邮。
  请看[开设账户](/portal/creating-an-account)。
- **一个安全的地方，用来保存十个恢复码。** 本站完全不发电邮，所以没有重设链接。
  这些恢复码是您自行回到账户的唯一途径。请看[恢复码](/portal/recovery-codes)。
- **申请时要有网络**，因为申请表单本身是 Google 表单，会在新标签页打开。
  请看[申请职位](/portal/applying)。

您不需要准备文件、履历，也不需要照片。本站任何地方都不接受上传文件，
唯一会拍的照片是您自己的头像，而且是选用的。

## 关于电邮的两件事，只说一次

本站没有电邮。我们不会向您留下的地址发送任何东西。
问您要地址，是为了帮您填进申请表单，也让您多一个登录的方式。

团队需要告诉您的一切，都会出现在您这里的账户中，也就是[待办事项](/portal/outstanding-tasks)页面。
如果您也想在 Telegram 上收到通知，可以稍后绑定，我们不会只发到那里而不发到这里。

## 英文与华文

整个网站都有英文和华文两个版本，职位信息也一样。用页首的地球图标切换，
选择会记在那个浏览器里。还没有人翻译的职位仍然会显示，并标注为 **仅有英文版**。
把真实的空缺藏起来，不让翻译要服务的人看到，那才是更糟的失败。

您正在读的这个说明文件网站有自己的语言控件，在它自己的页首。
它不会从入队平台带过来，也不可能：两者是不同的网站，而浏览器是按网站分别记住这个选择的。

## 本站仍在建设中

国际兽视入队平台是公开地分阶段发布的。尚未做好的功能会在控件上直接说明，不会默默失败。
[开发进度页面](https://careers.globalfurry.tv/status)列出每个阶段以及是否已经上线。
控件上写着「将于第 5 阶段推出」，那是计划，不是故障。
