# 恢复码

本站没有电邮。我们不会寄任何东西给您，也没有重设链接，
所以恢复码就是您自行回到账户的方式。一共有 **两组**，
它们做的事不同，各自在对方的场合都不被接受。

两组都在 **登录与安全**，网址是
[careers.globalfurry.tv/account/security](https://careers.globalfurry.tv/account/security)。

| | 账户恢复码 | 双重验证备用码 |
| --- | --- | --- |
| 有几个 | 十个，各用一次 | 十个，各用一次 |
| 有什么用 | 设置新密码 | 通过登录的第二步验证 |
| 在哪里用 | 找回账户页面 | 登录页面，输入密码之后 |
| 能设置密码吗 | 可以 | 绝不可以 |
| 什么时候拿到的 | 注册之后立刻 | 您生成它们的时候 |

## 账户恢复码

单靠其中一个，不需要别的，就能为您的账户设置新密码。
请把它当密码看待：任何拿到一个恢复码的人都能夺走这个账户。

注册时您看过十个，只看那一次。要使用其中一个，请到
[找回账户](https://careers.globalfurry.tv/forgot-password)，
输入您的用户名或电邮和一个恢复码，然后设置新密码。

用这个方式设置新密码会：

- 用掉那个恢复码，
- 退出所有其他浏览器的登录状态，
- 并移除这个账户上的所有受信任设备。

**如果账户设有通行密钥，通行密钥也会一并要求验证**，
或用一个双重验证备用码代替。这是刻意的：丢失一个恢复码不应该足以让别人接管账户。

## 双重验证备用码

另外一组十个。当您联系不上 Telegram，或拿不到装有通行密钥的设备时，
它们可以让您通过登录的第二步验证。它们永远不能设置密码，在找回账户页面上也一律不被接受。

请在需要它们之前先生成。在您生成之前，网站不会让您打开登录时的 Telegram 验证码。
您添加第一个通行密钥时，网站也会基于同样的理由提醒您。
那个通行密钥属于您刚才用的那台设备，所以在别处登录时都需要备用码，
直到您在那边也添加通行密钥为止。

## 生成一组

在 **登录与安全** 页面上，每一组都有自己的 **生成新的一组**。
每一个都会要求输入您目前的密码。这会改变登录的方式，光有登录状态并不足够。

> [!WARNING]
> 生成新的一组会立刻作废那一组里的所有旧码。另一组不受影响。
> 新的恢复码只展示一次，之后无法找回，只能再生成一组。

每一组都会显示还剩几个。剩下不到三个时，页面会说明并请您生成新的一组。
剩下零个时，它会说明那代表什么：

- **账户恢复码用完了**：没有恢复码，就没有人能自行让您回到账户。
- **双重验证备用码用完了**：请在需要之前先生成一组。

## 保存方式

- **复制** 会把整组放进剪贴板。**下载** 会保存一个带日期的纯文本文件。
- 请存在一个即使您弄丢了正在阅读本文的这台设备，仍然拿得到的地方。
  密码管理器、私人笔记，或纸张都可以。
- 不要把它们放在任何聊天里，包括跟自己的聊天。

## 如果密码和恢复码都丢了

没有恢复码的人无法自行回去。无论怎么向网站证明都没有用，因为已经没有东西可以让它核对。

在管理员确认您的身份之后，可以由管理员为您重设密码。
请在国际兽视的 Telegram 群组，或您平时联系团队的渠道提出。
预计他们会问一些只有您才知道的事情。

这是本站唯一需要人来做判断的部分，所以值得避免走到这一步。
一发现快用完了，就立刻生成新的一组。
