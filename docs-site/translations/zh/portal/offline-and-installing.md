# 离线使用与安装

国际兽视入队平台会保存您已经打开过的内容，所以断网时您可以继续阅读，
而不是遇到浏览器的错误页面。它也可以安装到主屏幕，像应用程序一样打开。

## 会保存什么

- **您打开过的网站页面**，包括职位板、职位信息本身，以及您的账户页面。
- **您打开过的职位**，大约一百则。列表满了之后，最久没看的会先让位。
- **您自己的账户资料**：您的申请、收藏的职位，以及待办事项，以最后一次载入的内容为准。
  每一页都会说明副本是哪一天保存的，以及在恢复网络之前页面上的内容无法更改。

这些资料保存在设备上，属于当时登录的那个账户，退出登录时会清除。

## 什么需要网络

网站会在控件上直接说明，不会默默失败：

- **登录。** 您已经打开过的内容在断网时仍然可以阅读，但那是断了网，不是退出了网站。
- **申请**，因为它会打开该职位在 Google 上的申请表单。
- **更换头像**，因为文件要送到我们这里。
- **回复待办事项。**

## 离线时的页面长什么样

- **顶部有一条横幅**，说明您目前离线，以及您已经打开过的内容仍然可以阅读。
  还有另一个版本，用于您的网络正常但联系不上国际兽视入队平台的情况，
  那个版本会链接到进度页面。
- **一个离线页面**，用于从未保存过的地址。它会说明没有出错，也没有东西丢失。
  它会列出您仍然可以阅读的职位和您收藏的职位，并提供重试这一页的选择。

## 有两样东西会自行稍后送出

您可能在没有网络时回答了申请后的那个面板。它的两个部分，
也就是评分和是或否的回答，都会保存在您的设备上，等网络恢复后自行送出。

**排队中的回答是等待送出，不是已完成。** 在服务器确认之前它不算一次申请，
在那之前也不会启动三个月的等待期。申请控件会说明它正在等待送出。

其他东西一律不会排队。回复待办事项是对一个问题的自由作答，
而那个问题到送出时可能已经改变。所以网站会在离线时停用那个控件，并说明原因。

## 有新版本时

新版本绝不会在您不知情的情况下自行替换。画面上会出现一条小横幅，
说明新版本已经就绪，附上 **重新载入** 和 **暂时不要**。
按下重新载入时才会替换。

如果您正读到一则职位的一半，这一点很重要。什么都不会在您眼皮底下改变，
而按下暂时不要不会有任何损失，只是稍后会再看到那条横幅。

## 安装

国际兽视入队平台可以安装到主屏幕或桌面，安装后会在自己的窗口里打开，有自己的图标。

网站上没有安装按钮。请用您浏览器自己的控件，各家浏览器不同：

:::tabs
::tab Android，Chrome

在网站上时，菜单里会有 **添加到主屏幕** 或 **安装应用**。
有些版本会在地址栏里显示提示。

::tab iPhone 或 iPad，Safari

按分享控件，然后选 **添加到主屏幕**。

::tab 桌面版 Chrome 或 Edge

在网站上时，地址栏右侧会出现安装控件。
浏览器菜单里也有同样的选项，在 **安装** 或 **应用** 下面。

::tab 桌面版 Firefox 或 Safari

这两者目前都无法把网站安装成应用。这一页上的其他功能仍然可用，包括离线阅读。
最接近的做法是加入书签。

:::

安装后的版本就是同一个网站。它的离线表现和标签页完全一样，
同样的四件事一样需要网络。

## 如果离线阅读没有生效

网站必须至少在有网络的情况下打开过一次，这些功能才会存在。
有些浏览器在隐私窗口里也会关掉它。
如果您之前打开过某一页，它却仍然拒绝离线显示，请看[疑难排解](/portal/troubleshooting)。
