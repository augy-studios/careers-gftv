# 开设账户

申请职位和收藏职位需要账户。浏览职位板和阅读职位则完全不需要。
您可以在 [careers.globalfurry.tv/register](https://careers.globalfurry.tv/register) 开设账户，
或者在任何职位上按申请，网站会在过程中让您注册。

> [!NOTE]
> 目前列出的每个职位都是义务性质，没有报酬。没有薪水、没有津贴，也不报销开支。
> 这一点值得在注册之前先看，而不是注册之后。

## 表格会问什么

| 栏位 | 用途 |
| --- | --- |
| 用户名 | 您登录时用的名称。可用字母、数字，以及 `.` `_` `-`，长度 3 至 32 个字符。 |
| 显示名称 | 团队在您的申请旁看到的名称。 |
| 电邮 | 用于登录，并会预先填入申请表单。我们不会向它发送任何东西。 |
| 密码 | 至少 10 个字符。密码的强度取决于长度，因此一句短语胜过一串短乱码。 |

电话号码是选填的，这里不会问。您可以稍后在[账户设置](/portal/account-settings)里补上。
它只在某个职位的申请表单要求填写时才会用到，好让我们帮您填进去。

## 注册后马上会发生什么

账户立即生效。没有等待审批、没有排队，也没有验证电邮这一步，因为整个流程根本不涉及电邮。

接着网站会向您展示 **十个账户恢复码**，只展示一次。每个码只能用一次，
而且单靠其中一个就能为您的账户设置新密码。

> [!WARNING]
> 这是唯一一次展示这些恢复码。之后无法找回，只能重新生成一组。
> 请复制或下载，并保存在只有您能取得的地方。

画面上有 **复制** 和 **下载** 两个选择，并且要您勾选「我已把这些保存在安全的地方」才让您继续。
下载的文件是纯文本，上面有日期。

本站没有电邮，也就是说没有「把重设链接寄给我」这回事。
这些恢复码就是回去的路。[恢复码](/portal/recovery-codes)完整说明了两组码。

![注册后立即展示一次的恢复码。图中的恢复码是虚构的。](pending:portal-recovery-codes-desktop-light "这十个恢复码只展示一次，不会再出现。图中的是示例，不是真实的恢复码。")

### 如果恢复码没有出现

偶尔会有账户建好了但恢复码没有生成的情况。网站会照实说明，
处理方法是立刻到账户里的 **登录与安全** 生成一组。
一个没有恢复码的账户，是没有人能帮您自行找回的账户。

## 账户能让您做什么

- **申请职位**，这是主要用途。
- **收藏职位**，收在您的[收藏职位](/portal/saving-roles)页面。
- **每一次申请的记录**以及后续结果，在[我的申请](/portal/your-applications)。
- **一个团队可以联系您的地方**，也就是[待办事项](/portal/outstanding-tasks)。
  本站没有电邮，所以问题或邀请都会落在那一页。
- **在任何职位上回报翻译问题**。这需要账户，好让有人可以就此回复您。

## 它不做什么

- 它永远不会用电邮寄东西给您。
- 它不保存您的申请答案。那些会交给 Google 表单，留在 Google 那边。
- 它不接受上传文件。唯一的例外是选用的头像，而且会先在您的浏览器里缩小再送出。
