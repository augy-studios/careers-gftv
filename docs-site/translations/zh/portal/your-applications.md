# 我的申请

您申请过或开始申请过的所有职位都在
[careers.globalfurry.tv/account/applications](https://careers.globalfurry.tv/account/applications)，
最新的排在前面。之后关闭的职位仍然留在列表上，所以您随时可以重读自己申请过的内容。

您的账户概览会以方块显示同样的三个数字：申请、收藏职位，以及待办事项。

![我的申请，列表上方有四个筛选分页。](pending:portal-applications-desktop-light "所有申请，最新的排在前面。已关闭的职位仍留在列表上。")

## 四个分页

- **全部**
- **进行中**，指已开始但尚未确认，或正在等团队处理。
- **已申请**
- **已结束**

## 每个状态的意思

| 状态 | 意思 |
| --- | --- |
| 已开始 | 您打开了申请表单，还没有告诉我们是否已提交。回答那个问题，它就会往前走。 |
| 已申请 | 您确认了自己已申请。团队收到了。 |
| 审阅中 | 有人正在读它。 |
| 已入围 | 您进入了这个职位的候选名单。 |
| 面谈中 | 团队正在安排或已安排与您谈一谈。 |
| 已发出邀约 | 这个职位已经提供给您。 |
| 已录取 | 您拿到这个职位了。从此那则职位对您关闭。 |
| 这次不合适 | 这一次没有选上您。这不代表下一次。 |
| 已撤回 | 您撤回了申请。 |

状态是由团队里的人更改的，所以它按自己的节奏推进。
这一页上没有任何东西是靠计时器走的，一个职位停在 **已申请** 一段时间，
意思是还没有人接手。

本站没有电邮，所以状态变动不会寄到您的收件箱。
它会出现在这里，如果您绑定了 Telegram，也会出现在那里。

## 会问您问题的那些行

带有未回答问题的那一行会写着 **回答关于这一则的问题**，
并重新打开[申请职位](/portal/applying)里说的那个面板。
在回答之前，您无法对同一个职位开始另一次申请。

## 撤回

多数申请都有 **撤回**。已经撤回的不会再提供这个选择。
团队已经以录取或这次不合适结案的也不会，因为已经没有什么可以撤回了。
它会请您确认，并在您确认之前说明它的作用：

- 团队不再把您列入这个职位的考虑。
- 等待期会一并清除，所以如果您改变主意，可以再申请。
- 团队看得到您撤回了，以及时间。

您已经透过该职位申请表单送出的内容由 Google 保存，撤回不会删除它们。
如果您需要移除，请联系团队。

## 离线

这一页会在您的设备上保留一份副本，没有网络时也打得开。
它会说明副本是哪一天保存的，在恢复网络之前，页面上的任何内容都无法更改。
