# 寻找职位

所有开放的职位都在同一页：
[careers.globalfurry.tv/search](https://careers.globalfurry.tv/search)，
称为 **寻找职位**。这一切都不需要账户，筛选功能也一样。

首页也有通往同一个职位板的捷径：搜索框、最新空缺、精选职位，以及有空缺的团队。

![桌面宽度下的职位板，筛选面板在结果旁边展开。](pending:portal-search-desktop-light "寻找职位。宽屏上筛选面板在结果旁边，手机上则由一个按钮打开。")

## 搜索

在搜索框里输入，网站会边打边给建议，分成三组：**职位**、**标签** 和 **团队**。
选一个建议就直接过去。您最近的搜索会记在那个浏览器里，也可以从同一个面板清除。

搜索会读整则职位而不只是标题，所以写在工作内容里的一项技能也找得到。
标题里的词分量最重，接着是标签和团队，然后是摘要，最后是其余内容。

> [!NOTE]
> 华文搜索的运作方式不同，与其让您猜，不如直说。
> 英文搜索理解词语，并按匹配程度排列结果。华文搜索比对您输入的字，
> 因为数据库无法把华文切分成词。两者都找得到存在的内容，只是英文才按相关度排序。

如果没有匹配的结果，页面会说明，并提供最接近的职位，或一个可以作为起点的标签。
它绝不会默默给您看别的东西。

## 快捷筛选

结果上方有四个快捷选项，对应大家最常问的几件事：

- **今天发布**
- **本周发布**
- **即将截止**
- **没有截止日期**

它们可以和其他条件叠加使用，按一下就清除一个。

## 筛选

宽屏上筛选面板在结果旁边。手机上则是一个按钮，会覆盖在页面上打开，底部有 **显示结果**。

| 筛选条件 | 作用 |
| --- | --- |
| 团队 | 职位所属的部门。每则职位刚好属于一个团队。 |
| 标签 | 技能和特质，例如欢迎新手。可以选任意多个。 |
| 符合所有已选标签 | 关闭时，符合任一标签的职位都会出现。开启时，必须全部符合。 |
| 投入程度 | 全职、兼职、义工、合约或实习。 |
| 地点 | 自由输入，与职位的地点比对。 |
| 远程 | 远程或现场、只要远程，或只要现场。 |
| 排序 | 最佳匹配、最新优先，或最快截止。 |

结果上方的数字说明有多少职位符合，**清除所有筛选** 会回到全部职位。
当没有职位符合每一项条件时，页面会说明，并建议去掉其中一项，这通常比全部改掉更有用。

### 关于投入程度

**投入程度说的是这个职位要花多少时间，不是它给多少报酬。**
一则职位可以写着全职，同时仍然是全职的义工职位。
目前列出的每个职位都没有报酬，每张卡片上都有 **无报酬义务职位** 的标记自行说明这一点。

## 一张卡片会告诉您什么

- 标题、团队和地点，适用时会标示 **远程**。
- 投入程度，以及无报酬的标记。
- 最多几个标签，还有其他标签时会显示 **+3 更多**。
- 发布时间：今天、昨天、几天前，或一个日期。
- 截止时间，或 **招满为止**。
- **仅有英文版**，当职位还没有翻译成您正在阅读的语言时。
  它仍然会显示，绝不隐藏，并在职位顶部附上说明，让您可以要求优先翻译。

## 招满为止

意思是这则职位没有截止日期。申请会随到随看，找到人之后职位就关闭。
没有隐藏的截止期限，也没有东西会默默过期。

有日期的职位会显示日期，两周内截止的会在卡片上标示 **即将截止**。

## 已关闭的职位仍然可以阅读

职位关闭之后，那则职位仍然留在原处。它会说明不再接受申请，如果原本有日期也会附上关闭日期。
什么都不会删除，好让您仍然读得到自己申请过的内容。

已归档的职位则更进一步。它完全离开职位板，但如果您申请过或收藏过，仍然打得开。
它会说明自己已归档，是作为记录保存，不是空缺。

## 职位本身

职位页面包含全部内容。关于这个职位、您会做什么、需要您具备什么，以及加分项。
团队、地点、投入程度、名额、标签和日期。顶部是 **申请这个职位**，
旁边有一个 **分享** 控件可以复制链接。

每则职位的底部是 **回报翻译问题**。如果译文读起来不对，团队就是靠那条链接知道的。
回报需要账户，好让有人可以就此回复您，而且每一份回报都有人读过才会有所改动。
