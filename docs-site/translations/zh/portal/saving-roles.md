# 收藏职位以后再看

每则职位都有一个收藏控件。按下它，职位就留在您的收藏列表里，
这样您不必再搜索一次就能回来看。

收藏需要账户，因为这个列表必须属于某个人。如果您没有登录，
控件会让您登录，之后再把您带回那则职位。

**收藏不等于申请，也不会通知任何人。** 这是只属于您的私人列表，团队看不到您收藏了什么。

## 您收藏的职位

列表在
[careers.globalfurry.tv/account/saved](https://careers.globalfurry.tv/account/saved)，
位于您账户中的 **收藏职位**。最近收藏的排在最前面，每一则都附上您收藏的日期。

三个分页：

- **全部**
- **仍然开放**
- **已关闭**

## 收藏的职位关闭时

它会留在列表上，并说明已关闭。不会有东西从您眼前消失，
您仍然可以打开那则职位，读它当初的要求。这正是保留它的意义。
一个您收藏了却没来得及申请的职位，值得知道它的下落，而一个默默变短的列表什么也没告诉您。

## 移除收藏

再按一次收藏控件，在职位上或在收藏列表上都可以。
它会立刻移除，之后随时可以再收藏。

## 收藏的职位可以离线使用

您收藏的职位会保存在设备上，所以没有网络时列表也打得开。
那是一份副本，页面会说明是哪一天保存的。任何会改动职位的操作，包括申请，都需要网络。

[离线使用与安装](/portal/offline-and-installing)完整说明了什么会保存、什么不会。
