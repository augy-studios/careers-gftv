# 国际兽视入队平台说明文件

这里是国际兽视入队平台和 Telegram 机器人的使用指南，也包括如何帮忙翻译。

**这些指南是一篇一篇写的**，每一篇都在功能做好之后才写。三本公开指南现在都写好了：

- [使用入队平台](/portal)，从开设账户，到忘记密码后重新登录。
- [使用 Telegram 机器人](/bot)。这是选用的，可以收到通知、更快登录，还有邀请。
- [帮忙翻译](/translations)，欢迎任何看得懂本站语言的人。

入队平台本身已经做好，也在使用中：
[careers.globalfurry.tv](https://careers.globalfurry.tv)。
