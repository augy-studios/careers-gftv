# 帮忙翻译

国际兽视入队平台以英文和华文发布，两个版本都应该读起来像是用那个语言写的。
国际兽视里不一定有人两种语言都好到能在读者之前发现坏译文。

所以读者就是纠错的回路。这一部分说明怎么参与。

这一部分刻意公开。最有能力修好华文的人说的就是华文，
而且完全没有理由必须是国际兽视的员工。

## 两条路，其中一条什么都不需要

- **回报问题。** 任何账户都可以做，从任何职位的底部。
  不需要角色、不需要培训，也不必提出替代写法。
  请看[回报问题](/translations/reporting-a-problem)。
- **成为翻译帮手。** 这是一个长期角色，一次授予一种语言，
  让您可以在整个网站上撰写和改进那个语言。
  请看[成为帮手](/translations/becoming-a-helper)。

## 什么需要翻译

- **职位。** 标题、摘要、职位描述、您会做什么、需要您具备什么、加分项，以及地点。
- **团队和标签**，也就是筛选条件上的名称。
- **界面本身**，也就是网站上的每一个标签、按钮和讯息。

没有翻译的职位仍然会发布。它会带着 **仅有英文版** 的说明出现。
把真实的空缺藏起来，不让翻译要服务的人看到，那才是更糟的失败。

## 什么永远不翻译

**标签和部门的短代号。** 短代号是地址里的简短标识，例如 `camera` 或 `post-production`。
筛选靠它比对，分享出去的链接也带着它。

翻译它会让每一条已经分享出去的链接失效。
所以短代号维持原样，被翻译的是短代号旁边的 **名称**。

## 两种语言在搜索上并不对等

英文搜索理解词语，并按匹配程度排序。
华文搜索比对您输入的字，因为数据库无法把华文切分成词。

两者都能用，只是英文才排得好。
在您断定华文搜索坏了之前，这一点值得先知道。
