# 帮手不能做什么

帮手可以自由撰写和改写一种语言。**帮手不能让翻译上线。**

只有管理员能设定就绪标记，而那正是读者所依赖的东西。
在管理员设定之前，您写的内容留在数据库里，帮手区域以外的人都看不到。

## 原因，直说

如果不说明原因，这看起来像不信任，所以原因在这里。

**可以先给权限，信任可以后建立。** 有人第一天就能拿到工具，
因为出错的代价是有上限的。在有人读过之前，他们写的东西不会送到读者面前。

**做到一半的职位不会意外送出去。**
在处理一段职位描述时，保存是您会做二十次的动作。
如果保存就等于发布，那二十次里总有一次会在句子中间送出去。

这条规则用别人多做一步，换来上面两件事。

## 这个标记实际上在守什么

翻译只有在被标示为就绪之后才会显示。在那之前：

- 职位会以原文语言显示，并带着 **仅有英文版** 的说明。
- 您留空的任何栏位都会回退到原文，即使在标记设定之后也一样。
- 被标示为就绪的翻译 **必须** 具备该语言的标题、摘要和职位描述。

## 有两个例外，保存就等于发布

团队名称和标签名称没有草稿状态。
它们一经保存，就会在所有用到的地方出现。

网站在这两者的编辑器上都会说明。请看[帮手能做什么](/translations/what-a-helper-can-do)。

## 完成之后该做什么

什么都不用做。这里没有提交按钮，也没有队列要排。

管理员会在自己的稽核视图里看到完成的翻译，
那个视图列出哪些已翻译、哪些还没有。
如果某一项已经完成并搁置了一段时间，请在您平时联系团队的渠道说一声。
