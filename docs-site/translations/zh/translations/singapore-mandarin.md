# 新加坡华文

本站的中文是 **华文**，也就是新加坡华文，不是中国大陆的普通话。
国际兽视是新加坡的组织，文案读起来应该像是在那里写的。

这比较是用词的问题，不是语法的问题，而且差别是实在的。

## 重要的那些词

| 用 | 不用 | 意思 |
|---|---|---|
| 义工 | 志愿者 | volunteer，两者之中最明显的标记 |
| 华文 | 中文, 简体中文 | 书面语言的名称 |
| 电邮 | 电子邮件 | email |
| 营运 | 运营 | operations |
| 摄影棚 | 录影棚 | studio |
| 文件 | 文档 | document，纸本意义上的 |

**义工 是最需要用对的一个。** 本站几乎每一则职位都是义务职位，
所以这个词到处都是。这份表上没有别的词，
能像 志愿者 那样清楚地把一页标示成在别处写的。

## 表上没有涵盖时的判断标准

它在《海峡时报》上读起来自然，还是像一份北京的报纸？

这就是全部的规则。表上列的是大家最常弄错的那几个。

## 名称

国际兽视就是 **国际兽视**，入队平台就是 **国际兽视入队平台**。
凡是有人读中文的地方都用这两个，不要用英文原文。

拉丁字母和汉字之间要有一个空格，汉字和汉字之间绝不加空格。
所以是 Telegram 账户 有空格，而 关于国际兽视入队平台 没有。

**这个中文名称刻意不是 Careers 的翻译。**
那个词暗示有薪水，而这里每一个职位都没有报酬。
招聘 会把同样错误的意思带过来。入队 说的是加入团队，那才是这里提供的东西。

## 语言用自己的名字

在语言切换控件里，每一种语言都用自己的文字书写，永远不翻译。
**English** 就是 English，**简体中文** 就维持原样，
这样不论界面目前是哪一种语言，两个选项读起来都一样。

在其他地方，这个书面语言一律称为 华文。

## 简单说说字体排版

文件标注为 `zh-Hans-SG`，那才是这些文案实际的样子。

样式表里刻意没有指定任何中文字体。
您自己系统的字体本来就是对的那一个，
而指定某个字体会覆盖掉读者自己选的设定。

## 当您在写的时候

任何新写的内容都请对照上面那份表检查。
如果您在更正别人的用词，而唯一的问题就是这些词之一，请指明是哪一个。
那是最容易处理的一种回报。
