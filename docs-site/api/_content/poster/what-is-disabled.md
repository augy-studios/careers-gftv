# What you will see disabled

Careers@GFTV is released in phases, in public. Some of what you can see is not
built yet, and it says so on the control instead of failing quietly.

There are three reasons a control does not do what you expect, and they are
deliberately different from each other.

## 1. Not built yet

> Will be available in Phase 5. Sorry for the inconvenience caused.

The control is there, greyed out, and clicking it opens an explainer naming the
phase and what that phase covers.

**This is a plan, and not a fault.** Nothing is broken and nobody needs
telling. The [build status
page](https://careers.globalfurry.tv/status) lists every phase and what is
live.

The phase number is read from that same file, so a control and the status page
cannot disagree.

## 2. Switched off for the moment

> Temporarily unavailable while we fix something.

That feature works and an admin has turned it off, usually during an outage or
while something is being fixed. Sometimes there is a note saying more.

A line at the top of every dashboard page says how many features are off. It
comes back when somebody turns it back on. Nothing turns itself back on.

**Telling the two apart matters.** Being told that something you used last week
arrives in a future phase would make a real outage look like an unbuilt
feature.

## 3. Not yours

The control is **absent**. No grey, no explainer, nothing to click.

That is on purpose. Greyed out already means "coming in a later phase". Using
it for "you are not allowed" would make a permission look like a build status.

What is absent for a job poster:

- **Staff access** and **Applicant accounts**, missing from the sidebar.
- **Settings** and **Maintenance**, also missing from the sidebar.
- **Delete** on a posting, and **Delete** on tracking rows.
- **Unmatched submissions**, at the foot of the analytics page.

If you need one of those done, ask an admin. Nothing is hidden from you as a
judgement about you.

## The applications toggle

One switch worth knowing about even though it is not yours. An admin can close
applications across the whole board.

While it is closed, every Apply control is disabled on every role, and an
applicant is told the site is not taking applications. Postings stay readable
and nothing is deleted.

**It is a policy choice and it reads as one**, and it is not the same as
something being broken. If your postings suddenly cannot be applied to, ask
before assuming a fault.

A change takes about a minute to reach somebody who already has a posting open.

## When something is genuinely broken

Neither of the first two sentences, and no missing control: just an error.

Say what you were doing, on which posting, and roughly when. The site keeps an
audit log, and an admin can find the rest.
