# Writing in more than one language

The editor has one tab per language. **The first tab is the posting itself.**
Every other tab is that language's translation of it.

![The language tabs](pending:poster-editor-tabs-desktop-light "The editor on a translation tab, with the source wording beside each field.")

A posting may go out in one language only. Nothing forces a translation, and a
role nobody has translated still appears to everybody. It is marked **English
only** to the reader.

Hiding a real opening from the people a translation exists to serve would be
the worse failure.

## The reference column

On a translation tab, each field shows the **source wording** beside it. You
are never translating from memory or from another tab.

## What the three tab states mean

Each language tab carries its state, and the postings list shows the same three
words in its Languages column.

| State | What it means |
|---|---|
| Complete | Ticked as ready. Readers in that language see it. |
| In progress | Something is written and it is not ticked. Nobody sees it. |
| Not started | Nothing written in that language at all. |

**In progress is invisible to readers**, which is the point of it. Half a
translation is not a translation, and the reader gets the original instead.

## Ready needs three fields

**This translation is ready for readers to see** is the tick that makes a
language live. It cannot be ticked without a title, a summary, and a
description in that language.

The editor lists what is missing beside the tick. The database refuses it too,
so this is not a tickbox somebody can talk their way past.

Everything else is optional in a translation, exactly as it is in the original.

## Untick it to take one back

Unticking hides that language again immediately. Readers fall back to the
original. That is the way to withdraw a translation you have doubts about,
without deleting the words.

## The errors on another tab

Save with a problem on a tab you cannot see and the editor says which tab it is
on. A message about a field you are not looking at, with no tab named, would be
the worst version of this.

## What is not translated here

**Tag slugs and team slugs are never translated.** They are web addresses.
Translating one breaks every link somebody has shared.

**The link preview line is always served in English**, whatever you write on a
Chinese tab. See [The link preview line](/staff/poster/link-preview).

**The interface itself** is a different thing entirely. The words around your
posting come from the site's dictionary, not from you. A wrong one there is
fixed in the code and ships with a deploy.

## Who else can write a translation

Applicants can be given a **translation helper** role for one language. A
helper edits translations freely and cannot make one live. The ready tick is
staff's, here in this editor, and it is not offered to a helper anywhere.

They also see what is missing, which is a list you never have to keep yourself.
The public [translations guide](/translations) is what they read.
