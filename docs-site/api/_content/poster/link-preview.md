# The link preview line

Paste a posting's link into Discord, Telegram, or anywhere else, and a card
appears with a title and a line under it. **Link preview line** is that line.

The editor shows the card as it will look, under the field.

## Leave it empty and it does the right thing

Left empty, the preview uses the first sentence of the description. That is
usually right, and the editor says so.

Write your own when the first sentence is a poor opening on its own. A
description starting "This is one of three roles in the studio team" reads
badly as the only line somebody sees.

Keep it to one sentence. A preview card has room for very little.

## It is always served in English

> [!WARNING]
> Link previews are always served in English, whatever language the link was
> shared in. A Chinese line written on a translation tab will not appear in
> Discord or Telegram.

The reason is in how the previews work. The site that unfurls a link is a
machine fetching the page, and it has no language preference to offer. There is
nothing on this side to read.

So the field on a translation tab is honest about doing nothing today. Write it
if you like. Nothing renders it yet.

## What else the card carries

The **title** of the posting, and the site's own image. Neither is set per
posting.

The card does not carry the summary, the tags, the team, or the closing date.
One line is what you get.

## What it does not affect

**Search.** Nothing about this line changes how a posting is found on the
board or by a search engine.

**The posting page.** The line appears nowhere on the page itself.

It is one sentence, seen once, by somebody deciding whether to click. That is
the whole of it.
