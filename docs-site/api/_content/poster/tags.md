# Managing tags

**Tags** in the sidebar. Tags are how somebody filters the board, and that is
the only thing they are for.

Two tags that mean the same thing split a search in half. Half the roles are
under one and half under the other, and a filter finds neither set whole.

## Adding a tag to a posting

In the editor, type in the tag field to find one. Type something that matches
nothing and you are offered to create it.

**Look before you create.** "video editing" and "video editor" are two tags
doing one job. So are "3D" and "3d modelling" if nobody is careful.

## The list

Every tag, with two counts beside it:

- **On published**, the published postings carrying it.
- **On all**, every posting carrying it, drafts included. This is the number
  deleting it would affect.

**Only tags on no posting** filters to the orphans. Those are usually typos, or
tags from a posting somebody deleted. Clearing them keeps the type-ahead
honest.

## Names and languages

A tag has a name in each language. Write both when you can. A tag with no
Chinese name shows its English name to a Chinese reader.

**The web address of a tag never changes**, whatever you rename it to. That is
what keeps a filter link somebody shared working. It also means a badly chosen
slug is with you for good, so think for a moment when you create one.

## Colours

A tag can have a colour, or follow the theme.

**Follow the theme unless there is a reason.** A themed tag works in light and
dark mode and keeps working when the site's palette changes. A fixed colour
does neither, and a fixed pale colour is unreadable in dark mode.

Use a colour for a small set that means something together, and not for
decoration.

## Merging duplicates

**Merge** is the fix for two tags meaning one thing.

Every posting carrying the tag you are merging gains the tag you choose, and
the first tag is then deleted, along with its own translations.

The confirmation says how many postings move across. Read it. A merge cannot be
undone, and putting the old tag back does not put it back on those postings.

Merge into the better name, and not into the busier one. You are choosing the
name that will be on the board for the next year.

## Deleting

Deleting a tag takes it off every posting carrying it, drafts included. The
confirmation says how many.

Nothing else is affected. The postings themselves are untouched.

Delete an orphan freely. For anything else, merge it into the tag you would
rather people used.

## How many tags a posting should carry

At least one, because a posting cannot be published without one.

Three or four good ones after that. Every tag on a card is a word somebody
reads, and a card carrying nine of them says nothing.

Ask what somebody would type into the filter to find this role. Those are the
tags.
