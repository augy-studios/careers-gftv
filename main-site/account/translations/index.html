What is still waiting to be written in your language, and the place to write it. Nothing you save here goes live on its own.

This area is for translation helpers. An admin grants the role one language at a time. It lets you write and improve that language across the whole site.

Anyone can report a translation that reads wrongly from the link at the foot of any posting. That needs no role at all.

You can write and rewrite this language freely, with no approval and no waiting. A posting stays a draft until an admin marks it ready, so nothing you write there reaches readers before somebody has read it. A team or tag name has no draft state and changes as soon as you save.
