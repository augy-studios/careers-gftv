Account recovery codes

Ten codes, each usable once, that set a new password when you have forgotten yours. Treat one like your password: anybody holding a code can take the account.

Generating a new set immediately cancels every code in that set. The other set is untouched.

Two factor backup codes

A different set of ten, for getting past the second step of signing in when you cannot reach Telegram. They never set a password and they are never accepted on the recovery page.

Passkeys

A passkey is your fingerprint, your face, or a security key, used as the second step of signing in. There is no code to type and nothing to copy, and a passkey cannot be phished: your device will only use it on this site.

Your password is still asked for every time. Once you add a passkey, signing in becomes two steps.
