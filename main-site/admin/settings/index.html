Featured roles

Chosen roles appear first on the home page, in this order. With none chosen the home page shows the latest published roles instead.

Waiting period before reapplying

  • Zero switches the waiting period off entirely. Dates already stored are ignored, not cleared, so turning it back on restores them.
  • Changing this does not move a waiting period somebody is already serving. It applies to the next person who applies.
